\# Hospital Management System Database



This project represents a Hospital Database System designed and implemented using SQL.

All tables, relationships, and queries were created manually.



\---



\## Project Overview



The system includes core hospital entities such as:



Patients

Doctors

Departments

Appointments

Visits

Medical Records

Rooms

Payments



The database models real-world relationships between these entities.



\---



\## Database Structure



The database includes:



Primary Keys and Foreign Keys

One-to-Many relationships

One-to-One relationships



Example:



One patient can have multiple appointments

One doctor belongs to one department

Each appointment has one visit
